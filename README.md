# Smart Agriculture System

## Project Overview
This repository is being developed as a Smart Agriculture System project using embedded systems technology.

The objective is to develop an intelligent agricultural monitoring system using sensors and a microcontroller.

## Hardware Components (Planned)
- ESP32 Development Board
- DHT11 Temperature and Humidity Sensor
- Soil Moisture Sensor
- LDR Sensor
- MQ Gas Sensor
- LCD Display

## Planned Features
- Temperature and humidity monitoring
- Soil moisture monitoring
- Light intensity monitoring
- Gas detection
- Real-time sensor data display

## Development Tools
- Arduino IDE
- Embedded C / C++
- ESP32
- Git and GitHub
